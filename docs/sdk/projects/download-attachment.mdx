`GET /v1/projects/{id}/attachments/{attachmentId}/content`

Downloads an Attachment's bytes. If unavailable after ten seconds, returns ATTACHMENT_NOT_READY with Retry-After: 5.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.projects.downloadAttachment({
  path: {
    attachmentId: "attachmentId",
    id: "id",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import DownloadAttachmentInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.projects.download_attachment(
    DownloadAttachmentInput.model_validate({
        "path": {
            "attachmentId": "attachmentId",
            "id": "id",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .download_attachment("attachmentId".to_owned(), "id".to_owned())
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```

## Returns

**`200`** The Attachment's raw file bytes. Content-Type identifies the media type of the response. The `*/*` body as bytes.

Headers: `Content-Disposition`. The raw response carries these headers; see [Raw responses](/api-client/raw-responses).
