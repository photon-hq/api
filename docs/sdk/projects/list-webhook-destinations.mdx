`GET /v1/projects/{projectId}/webhooks/destinations`

Returns a cursor-paginated page of active webhook destinations configured for the selected project. Use pageSize and pageToken to navigate it. The listing returns destination configuration, never signing secrets.


```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;

let result = client
    .list_webhook_destinations("projectId".to_owned(), None)
```
