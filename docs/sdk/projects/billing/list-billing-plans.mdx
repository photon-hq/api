`GET /v1/projects/{projectId}/billing/plans`

Lists the billing plan catalog, grouped by their public plan-metadata type. Use the returned plan information when choosing the category and planCode for a plan change. The catalog is the same for every project, and reading it does not purchase a plan.

## Parameters

<ParamField path="projectId" type={"string"} required>
The project being billed.
</ParamField>


## Returns

**`200`** Billing plans grouped by their public plan-metadata type. ListBillingPlansResponse

<ResponseField name="plans" type={"object"} required>
Plans grouped by valid metadata type and explicitly published with visible="true". Each group is in display order: by tier, plans without one last, then by planCode.
</ResponseField>
