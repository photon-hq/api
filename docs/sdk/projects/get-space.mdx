`GET /v1/projects/{id}/spaces/{spaceId}`

Returns one stored Space by canonical Photon Space ID. A Space of a kind its platform does not support returns OPERATION_UNAVAILABLE.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.projects.getSpace({
  path: {
    id: "id",
    spaceId: "spaceId",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import GetSpaceInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.projects.get_space(
    GetSpaceInput.model_validate({
        "path": {
            "id": "id",
            "spaceId": "spaceId",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .get_space("id".to_owned(), "spaceId".to_owned(), None)
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
