`GET /v1/projects/{projectId}/webhooks/egress-addresses`

Returns the public network addresses from which this environment sends webhook deliveries. Use this information when configuring the receiving system's network allowlist. The result is environment-specific and does not describe the API service's ingress addresses.

## Returns

**`200`** The public addresses webhook deliveries originate from in this environment. ListWebhookEgressAddressesResponse

<ResponseField name="ipAddresses" type={"array of string (ipv4)"} required>
Every public IPv4 address webhook deliveries can originate from. Allow-list all of them; deliveries are spread across every address.
</ResponseField>

**`304`** The authorized cached representation is current; no response body. No body.
