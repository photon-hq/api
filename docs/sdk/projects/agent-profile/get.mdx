`GET /v1/projects/{projectId}/agent-profile`

Returns the agent profile belonging to the identified project. The profile is project-scoped and is distinct from the authenticated account's personal profile. Use the dedicated avatar operations when uploading or removing an agent avatar.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.projects.agentProfile.get({
  path: {
    projectId: "projectId",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import GetAgentProfileInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.projects.agent_profile.get(
    GetAgentProfileInput.model_validate({
        "path": {
            "projectId": "projectId",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .get_agent_profile("projectId".to_owned())
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
