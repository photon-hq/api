`GET /v1/projects/{projectId}`

Returns the identified project's settings for an authorized caller. The credential must be allowed to access that project; possession of an unrelated project's key does not provide access. Missing and deleted projects are reported through the documented error responses.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.projects.get({
  path: {
    projectId: "projectId",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import GetProjectInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.projects.get(
    GetProjectInput.model_validate({
        "path": {
            "projectId": "projectId",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .get_project("projectId".to_owned())
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
