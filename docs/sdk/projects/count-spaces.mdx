`GET /v1/projects/{id}/spaces/count`

Counts distinct Spaces matching the list filters; multiple matching Messages count once. Results are eventually consistent.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.projects.countSpaces({
  path: {
    id: "id",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import CountSpacesInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.projects.count_spaces(
    CountSpacesInput.model_validate({
        "path": {
            "id": "id",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .count_spaces("id".to_owned(), None)
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
