`POST /v1/auth/organizations/{orgId}/sso/refresh`

Refreshes the selected organization’s SSO connection and returns its current connection state, configuration version and policy synchronization status. This operation takes no request body.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.auth.refreshOrganizationSsoConnection({
  path: {
    orgId: "orgId",
  },
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import RefreshOrganizationSsoConnectionInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.auth.refresh_organization_sso_connection(
    RefreshOrganizationSsoConnectionInput.model_validate({
        "path": {
            "orgId": "orgId",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .refresh_organization_sso_connection("orgId".to_owned())
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
