`GET /v1/organizations/{organizationId}/billing`

Returns the selected organization’s billing subscription and entitlementsVersion. The subscription can be null. Read the returned plan, charges and entitlements to inspect organization billing; this operation does not purchase or change a plan.

## Returns

**`200`** The organization-owned plan and its resolved entitlements. GetOrganizationBillingOverviewResponse

Headers: `ETag`, `Photon-Version`. The raw response carries these headers; see [Raw responses](/api-client/raw-responses).

<ResponseField name="currentPeriod" type={"OrganizationBillingPeriod | null"} required>
Charges so far this billing period, for an organization that pays by invoice; null for one that pays by card, or while its projects are still being moved to its billing day.
</ResponseField>

<ResponseField name="entitlementsVersion" type={"integer"} required>
Bumps on every entitlement change for the organization.
</ResponseField>

<ResponseField name="subscription" type={"OrganizationSubscription | null"} required>
The organization-owned subscription, or null when billing was never opened or has ended.
</ResponseField>
