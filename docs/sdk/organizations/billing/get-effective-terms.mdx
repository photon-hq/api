`GET /v1/organizations/{organizationId}/billing/projects/{projectId}/terms`

Returns what the selected project is billed on now, per category it holds: the plan as its subscription has it, with any override applied, each fixed charge at the subscription's price and quantity, and resolved entitlements; where the plan comes from; how invoices are paid; the current period and next billing date; and any downgrade or cancellation waiting for the period end. It also returns the credit the paying organization holds on credit notes, such as the unused time of a plan an upgrade replaced; it offsets that organization's next invoices. Supply both organizationId and projectId; the organization must pay for the project. This operation does not change billing.

## Parameters

</ParamField>

<ParamField path="projectId" type={"string"} required>
The project being billed.
</ParamField>


## Returns

**`200`** The project's effective billing terms, per category. GetEffectiveTermsResponse

<ResponseField name="creditBalance" type={"CreditBalance | null"} required>
Credit the paying organization holds on credit notes, such as the unused time of a plan an upgrade replaced. It offsets that organization's next invoices of any kind except one-off invoices. Prepaid wallet credit is separate. Null when it holds none.
</ResponseField>

<ResponseField name="subscriptions" type={"array of SubscriptionTerms"} required>
One entry per category the project holds, by category. Empty means it holds none.
</ResponseField>

<ResponseField name="timeZone" type={"string"} required>
The IANA time zone the payer is billed in, e.g. America/Los_Angeles. Billing periods start and end at its midnights, so read their calendar dates in it.
</ResponseField>
