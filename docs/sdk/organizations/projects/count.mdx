`GET /v1/organizations/{organizationId}/projects/count`

Counts the projects the same filter would list. The count is read from the primary, so it is authoritative rather than replica-lagged.

<RequestExample>
```typescript TypeScript
import { Photon } from "@photon-ai/api";

const photon = new Photon({
  headers: { Authorization: `Bearer ${process.env.PHOTON_API_TOKEN}` },
});
const result = await photon.organizations.projects.count({
  path: {
    organizationId: "organizationId",
  },
});
```

```python Python
import os

from photon_api import Photon
from photon_api.rpc_generated import CountProjectsInput

photon = Photon(headers={"Authorization": f"Bearer {os.environ['PHOTON_API_TOKEN']}"})
result = photon.organizations.projects.count(
    CountProjectsInput.model_validate({
        "path": {
            "organizationId": "organizationId",
        },
    })
)
```

```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;
let client = PhotonClientBuilder::new()
    .credential("accountServiceKey", Credential::Bearer(SecretString::from(token)))
    .build()?;
let result = client
    .count_projects("organizationId".to_owned(), None)
    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```
