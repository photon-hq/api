```rust Rust
use photon_ai_api::{Credential, PhotonClientBuilder, SecretString};

let token = std::env::var("PHOTON_API_TOKEN")?;

    .build()?;

    .await
    .map_err(|error| format!("{error:?}"))?
    .into_inner();
```

```go Go

	IdempotencyKey: "idempotencyKey",
})
if err != nil {
```

## Parameters

<ParamField header="Idempotency-Key" type={"string"} required>
Identifies one logical mutation across retries.
</ParamField>


## Returns

**`200`** Creates the caller's first owned organization, once per account. Never recreated after it is deleted or transferred. EnsureInitialOrganizationResponse

<ResponseField name="organization" type={"Organization | null"} required>
The initial organization this request created; null when the account already had one.
</ResponseField>
