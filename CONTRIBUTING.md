# Contributing

Please report bugs and request features through
[GitHub issues](https://github.com/photon-hq/api/issues).

This repository is generated from Photon's API contract and client tooling.
External pull requests are not accepted: a change made here would be
overwritten by the next release. Every change, including dependency and security
updates, is made upstream and reaches this repository with the next release;
`main` changes only at releases. Maintainer pull requests may change only the
community files (issue templates and the security policy).

Do not include credentials or private customer data in issues. Report security
problems privately as described in [SECURITY.md](SECURITY.md).
